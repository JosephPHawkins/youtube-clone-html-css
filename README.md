# YouTube Clone (HTML & CSS)

A front-end YouTube homepage clone built using **HTML and CSS**.  
This project replicates the layout and design of the YouTube home interface to practice structuring, styling, and responsive design.

---

## 🚀 Project Overview

This project demonstrates how to build a modern website layout using only **HTML and CSS**, focusing on the YouTube homepage.  
It includes a header, sidebar, and a responsive grid of video previews.

---

## 🧩 Features

- Responsive **header**, **sidebar**, and **video grid**
- Hover **tooltips** for interactive icons
- Uses **Flexbox** and **CSS Grid** for layout organization
- Clean, modular CSS split across files (`header.css`, `sidebar.css`, `styles.css`)
- Static mockup of YouTube’s main page for practice and learning
